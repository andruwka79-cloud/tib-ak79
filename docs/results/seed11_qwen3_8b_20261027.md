## Setup

- Arms: A plain; B gate; C gate with one-time notice; D gate with notice and independent reviewer (`llama3.1:8b`).
- Analysis: `python -m tib_ak79.analyze A B --out ...` run under **Python 3.14.7**. `tib_ak79/paired.py:80` uses a nested f-string that needs Python 3.12 or newer, so it fails with SyntaxError on 3.11; the 3.12 install on the machine was broken, hence 3.14.
- Bootstrap: 2000 resamples clustered by task. Reports say `Comparability: comparable` for A vs B, C and D.

## Caveats

- Preliminary and not significant: every interval for D includes zero except the 13-task score slice, whose lower bound is exactly 0.000; the McNemar tests do not reject.
- The `reviewer_degraded_runs` field is not present in these reports, so it was not possible to check how many D runs fell back to C.
- Arms B and C give identical scores to A; their only measured effect is on critical violations in a few tasks.
- Not compared with earlier runs at commits 6ac22d9f, c7d24c05 and 35ee8e0a.
