## Caveats

- Engineering observations, not a controlled comparison. One seed and one epoch for Haiku; the same Haiku configuration repeated in a second run varies by about 0.05 to 0.08, which is as large as the gaps in the table.
- Bare Haiku and the provider-layer runs are comparable only with limits. Scores here must not be read as a ranking of configurations or of models.
- The open task set is public; a model may have seen it.
- Hashes were taken from the author's machine; this repository does not contain the result JSON files. Harm for arms A and D is not recorded in this index.
